# EDF6 Launcher 0.4.1

**Скачать готовый exe:** [EDF6Launcher.exe](https://github.com/don-pardon42/edf6-mods/releases/download/launcher-v0.4.1/EDF6Launcher.exe) — положить в папку игры и запустить, собирать не нужно.

Маленький лаунчер для модов EDF6: один `EDF6Launcher.exe` (~0.9 МБ, ничего ставить не нужно), кладётся в папку игры.

Вид — в духе лаунчеров PC-игр нулевых: нарисованный кодом ночной город с муравьями на крышах, корабль-матка с лучом,
прожекторы и трассеры, косые металлические кнопки-плашки, наклейка «НОВОЕ!» при обновлениях и бегущая сводка внизу.
Никаких картинок из игры или чужих лаунчеров — весь арт процедурный.

- **Моды** — список из [`mods.json`](../mods.json) этого репозитория: установка, обновление, удаление,
  включение/выключение (выключенный мод = DLL в `Mods\Plugins\disabled`, EDFModLoader подпапки не загружает).
  Моды, которых нет в списке, тоже показываются — их можно включать, выключать и настраивать.
- **Обновление** — файлы качаются с GitHub Releases, проверяется SHA-256; старая DLL сохраняется как `.bak`.
  Ваши `.ini` не затираются: дописываются только новые параметры.
- **Настройки** — редактор `.ini` любого мода: комментарии становятся подсказками, 0/1 — галочками,
  клавиши (`...Key`) задаются нажатием.
- **Язык** — русский или английский по языку Windows (русский для ru/uk/be/kk); `Language=auto|ru|en` в `EDF6Launcher.ini`.
- **Играть** — запускает игру (`GameExe` в `EDF6Launcher.ini`, по умолчанию `EDF6.exe`).
- Проверяет, что EDFModLoader установлен, и не даёт обновлять моды при запущенной игре.
- **Самообновление** (с 0.4.0): в `mods.json` есть запись `launcher` (версия, ссылка, SHA-256); если она новее,
  на главном экране появляется наклейка, а в «Настройках» и «Модах» — кнопка «Обновить лаунчер». Новый exe проверяется
  по SHA-256, старый остаётся как `EDF6Launcher.exe.old` до следующего запуска.
- **Логи** (с 0.4.0), кнопки в «Модах» и «Настройках»:
  - «Собрать логи» — один zip в `EDF6Launcher_logs\` (логи и настройки всех модов, `ModLoader.log`, последний
    отчёт EDFStats и отчёты трёх последних миссий, `info.txt` с версиями), папка открывается с выделенным архивом —
    его можно перетащить в Discord/Telegram;
  - «Отправить логи друзьям» — тот же архив по локальной сети / VPN на адреса из `Peers` (EDFStats.ini или
    SquadSync.ini, либо `LogPeers` в `EDF6Launcher.ini`), свой адрес пропускается;
  - пока лаунчер открыт, он принимает архивы на TCP-порту `LogPort` (27788) в `EDF6Launcher_logs\received\`
    («Полученные логи»). Принимается только zip до 100 МБ, ничего из полученного не открывается и не запускается.
    При первом запуске Windows спросит разрешение для брандмауэра — разрешите для частных сетей.

Настройки самого лаунчера — `EDF6Launcher.ini` рядом с exe (создаётся при первом запуске):
`GameDir`, `GameExe`, `GameArgs`, `CloseOnPlay`, `Manifest`, `Language`, а также `LogPort` (27788),
`ReceiveLogs` (1/0), `LogPeers` (адреса через запятую; пусто — из `Peers` модов).

## Сборка и проверка

```bat
Launcher\build.bat
Launcher\out\EDF6Launcher.exe --game-dir C:\temp\fakegame --selftest-install   & rem ставит все моды в тестовую папку, отчёт в out\selftest.txt
Launcher\out\EDF6Launcher.exe --screenshot out\shot.bmp                         & rem рисует окно в картинку
Launcher\out\EDF6Launcher.exe --game-dir <папка игры> --selftest-logs            & rem собирает логи, шлёт их сам себе (порт 27799), сравнивает
Launcher\out\EDF6Launcher.exe --selftest-selfupdate <mods.json>               & rem обновляет сам себя по записи launcher из локального mods.json (без перезапуска)
```

## Выпуск новой версии мода

1. Положить файлы мода в `_release\<Мод>\`, поднять версию в `tools\make_manifest.py`.
2. `gh release create <мод>-v<версия> _release\<Мод>\*.dll _release\<Мод>\*.ini`
3. `python tools\make_manifest.py`, закоммитить и отправить `mods.json` — у всех лаунчер предложит обновиться.
