EDF6 Launcher 0.4.1
===================

RU
1. Сначала установите EDFModLoader (winmm.dll, EDFModLoader.dll, ModLoader.ini) в папку игры:
   https://github.com/BlueAmulet/EDFModLoader/releases
2. Положите EDF6Launcher.exe в папку игры, рядом с EDF6.exe (старый лаунчер можно просто заменить).
3. Запустите EDF6Launcher.exe и нажмите «Установить» у нужных модов. Дальше лаунчер сам
   предложит обновления модов и самого себя («Обновить лаунчер» в настройках), а кнопка «Играть» запускает игру.
   Ничего дополнительно ставить не нужно. Настройки лаунчера появятся в EDF6Launcher.ini.
4. Логи: «Собрать логи» складывает все логи и отчёты в один zip, «Отправить логи друзьям» шлёт его
   по локальной сети / VPN на адреса из Peers. При первом запуске разрешите лаунчер в брандмауэре Windows.

EN
1. Install EDFModLoader (winmm.dll, EDFModLoader.dll, ModLoader.ini) into the game folder first:
   https://github.com/BlueAmulet/EDFModLoader/releases
2. Put EDF6Launcher.exe into the game folder, next to EDF6.exe (an older launcher can simply be replaced).
3. Run EDF6Launcher.exe and press Install for the mods you want. The launcher offers updates of the mods and
   of itself ("Update the launcher" in the settings); Play starts the game. Settings go to EDF6Launcher.ini.
4. Logs: "Collect logs" packs every log and report into one zip, "Send logs to friends" sends it over the
   LAN / VPN to the addresses in Peers. Allow the launcher in Windows Firewall on the first start.

Source and mods: https://github.com/don-pardon42/edf6-mods
