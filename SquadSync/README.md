# SquadSync

Каждый игрок раз в 1/30 секунды отправляет остальным позицию своего персонажа по небольшому
UDP-каналу (адреса из `SquadSync.ini`). Если на вашем компьютере персонаж другого игрока
заметно отстал от своей настоящей позиции, мод плавно подтягивает его (или телепортирует при
большой ошибке). Трогает только персонажей других игроков — не ваш, не NPC и не врагов.

## Настройка

В `SquadSync.ini` впишите IPv4-адреса **других** игроков (LAN, Radmin VPN, ZeroTier) в `Peers`
и разрешите UDP-порт `27777` в брандмауэре Windows. `F8` включает и выключает коррекцию в игре.

## Исходник

Исходник версии 0.1 потерян вместе с диском; в Releases выложена готовая DLL.
Его можно восстановить по DLL (она собрана из нашего же кода без защиты) — это отдельная задача.
