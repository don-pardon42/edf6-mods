# EDFStats

Статистика игроков EDF6 в кооперативе. Каждый игрок ставит плагин у себя: его компьютер точно
считает урон своего персонажа и рассылает цифры остальным через сетевое соединение самой игры
(Epic Online Services, отдельный канал `EDFStats`), так что у всех получается одинаковая общая таблица.

## Что считается

- урон по врагам, в том числе с техники; попадания; самый сильный удар
- пиковый урон в секунду (окно 1 с и 5 с)
- убийства (по типам врагов) и уничтоженные части крупных врагов
- урон по своим: по игрокам / по союзным NPC / по себе
- полученный урон: всего (графа «Получено урона») и отдельно от врагов / от своих; смерти
- **по каждому оружию** (только в HTML-отчёте): урон, доля, попадания, убийства, лучший удар, пиковый DPS,
  DPS в бою; у Фенсера все четыре оружия считаются отдельно, техника — отдельными строками
- пройденное расстояние пешком и на технике

## Где смотреть

- **В игре**: `F6` — живая панель урона справа, `F7` — таблица. На экране наград таблица открывается сама.
- **После миссии**: `Mods\Plugins\EDFStats\latest.html` и архив `EDFStats\missions\*.html` / `*.json`.
- `F9` — записать итоги сейчас, `Ctrl+F10` — начать подсчёт заново. Клавиши работают, только когда активно окно игры.

## Настройки (`EDFStats.ini`)

| Ключ | Назначение |
|---|---|
| `Name` | Имя в отчётах. Пусто — имя профиля Steam |
| `ShareViaGame` | 1 — обмен через соединение игры (IP не нужны) |
| `Peers`, `Port` | Запасной канал UDP: адреса других игроков (LAN/VPN). Пусто — берутся из `SquadSync.ini` |
| `Overlay`, `OverlayScale`, `LivePanel`, `ScoreboardOnResult` | Окно в игре |
| `LivePanelKey`, `ScoreboardKey`, `SummaryKey`, `ResetKey` | Клавиши (virtual-key коды) |
| `LogHits` | 1 — писать каждый удар в лог (только для отладки) |
| `WeaponProbe` | 1 — писать в лог, как удары сопоставлены с оружием (первые 60 ударов миссии и каждое новое оружие) |

## Как это устроено

- `GameObjectBase::ApplyDamage` (`EDF.dll+547960`) — через неё проходит весь урон.
  HP цели меняется только на компьютере стрелявшего, поэтому каждый считает своего игрока.
- Свои/чужие — по таблице отношений команд самой игры (`ApplyDamage+0x19B`).
- Водитель техники — `SoldierBase+0x1548`.
- Конец миссии — конструктор экрана итогов `ui::HUiMissionResult` (`EDF.dll+8D28C0`).
- Оружие — мод собирает оружие стрелявшего (в объекте персонажа или техники) и то, на что ссылается только одно
  из них (фабрика пуль, модель…). В момент удара по стеку вызовов ищется ближайшее: само оружие, пуля (`*Bullet*`)
  или запись о пуле этого игрока, которая ссылается на такое оружие или его объекты. Название — строка по
  смещению +0x1B0 объекта оружия. Удары без найденного оружия идут в строку «Не определено».
- Окно — Dear ImGui поверх `IDXGISwapChain::Present`, не перехватывает мышь и клавиатуру.

## Проверка без игры

`tests\build_tests.bat` собирает и запускает три теста: обмен статистикой (UDP и имитация EOS),
распознавание оружия и отрисовку окна (картинки `tests\out\live.bmp`, `board.bmp`).
