# MortarCam

Фенсер: по клавише камера поднимается над полем боя, пока экипирована мортира, — как вид бомбардировщика
у Air Raider'а. Работает только у вас, ничего не отправляет по сети.

**Версия 0.1 — пробная.** Камера поднимается, но смотрит туда же, куда вы целитесь. Плагин пишет
подробный лог (оружие в слотах, его состояния, расчётная точка падения снаряда) — по нему будет
доделана следующая версия. Пришлите `Mods\Plugins\MortarCam.log` после миссии с мортирой.

## Как это устроено

Своей камеры у мода нет. У каждого солдата есть блок настроек камеры (`game_object_camera_setting`),
и камера персонажа каждый кадр берёт либо обычный блок, либо альтернативный. Игра сама подменяет его,
когда Air Raider наводит бомбардировщик; MortarCam делает то же самое для Фенсера. Если игра в этот
момент сама использует подмену (свои режимы камеры), мод уступает.

## Настройки (`MortarCam.ini`)

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `Key` | `B` | клавиша: буква или код (`0x05` — 4-я кнопка мыши) |
| `HoldKey` | 0 | 0 — клавиша включает/выключает, 1 — камера поднята, пока клавиша зажата |
| `OnlyWithMortar` | 1 | работать только с мортирой (0 — с любым оружием, для проверки) |
| `MortarNames` | `Mortar` | части названий оружия, которые считаются мортирами, через запятую |
| `LookOffset` | `0,35,0` | куда смотрит камера относительно персонажа (x вправо, y вверх, z вперёд), м |
| `CameraOffset` | `0,70,-140` | где стоит камера относительно персонажа, м (как у Air Raider'а) |
| `TiltDegrees` | 0 | дополнительный наклон камеры, градусы (экспериментально) |
| `BlendSeconds` | 0.33 | за сколько секунд камера поднимается |
| `ProbeLog`, `ProbeLimit`, `StatusMs` | 1, 400, 1000 | подробный лог для разработки |

## Сборка и тесты

```bat
MortarCam\build.bat
MortarCam\tests\build_tests.bat
```

Тесты проверяют без игры смешивание блока камеры, передачу камеры между модом и игрой,
расчёт полёта снаряда и разбор настроек.
