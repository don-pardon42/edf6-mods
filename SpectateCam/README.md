# SpectateCam

Пока ваш персонаж мёртв, камера игры (`CharacterGhostCamera`) переключается между живыми солдатами;
когда вас поднимут, камера возвращается к вам. Работает только у вас, ничего не отправляет по сети.

## Клавиши (`SpectateCam.ini`)

| Ключ | По умолчанию | Действие |
|---|---|---|
| `NextKey` / `PrevKey` | `=` / `-` | следующий / предыдущий игрок |
| `NpcKey` | `9` | следующий NPC-солдат (с 0.4) |
| `SelfKey` | `0` | вернуться к себе |
| `DebugKey` | `\` | режим отладки: переключение в любой момент |
| `FreeCamera` | 1 | вращение камеры мышью вокруг чужого персонажа (с 0.4) |
| `Console` | 1 | список солдат в отдельном окне консоли |

## Исходник

В `src/` лежит исходник **версии 0.2** — более новые исходники потеряны вместе с диском.
Готовая версия **0.4** выложена в Releases как DLL. При следующей доработке исходник нужно
довести до 0.4 (клавиша NPC, свободная камера, `ExtraHeight`).
