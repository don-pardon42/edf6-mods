# Моды для Earth Defense Force 6

Плагины для [EDFModLoader](https://github.com/BlueAmulet/EDFModLoader) (PC, `EDF.dll` сборки 2024-06-03).
Все адреса в игре ищутся по сигнатурам; если игра обновится и сигнатура не найдётся, плагин
ничего не трогает и пишет об этом в свой `.log`.

| Мод | Что делает | Версия | Исходник |
|---|---|---|---|
| [EDFStats](EDFStats/) | Статистика игроков в кооперативе: урон, пиковый DPS, убийства, урон по своим, урон и DPS по каждому оружию, пройденный путь. Окно в игре и HTML-отчёт после миссии. | 0.15 | есть |
| [SpectateCam](SpectateCam/) | После смерти — камера следит за живыми союзниками, переключение клавишами. | 0.4 (в репозитории исходник 0.2) | частично |
| [MortarCam](MortarCam/) | Фенсер: по клавише камера поднимается над полем боя, пока экипирована мортира (как вид бомбардировщика у Air Raider'а). Пробная версия с подробным логом. | 0.1.1 | есть |
| [SquadSync](SquadSync/) | Подтягивает персонажей других игроков к их настоящей позиции, когда сетевая синхронизация игры отстаёт. | 0.1 | только DLL |

## Лаунчер

[EDF6 Launcher](Launcher/) — выбор, установка и обновление модов, настройки и запуск игры.

**Скачать:** [EDF6Launcher.exe](https://github.com/don-pardon42/edf6-mods/releases/download/launcher-v0.4.0/EDF6Launcher.exe) (или [архив с инструкцией](https://github.com/don-pardon42/edf6-mods/releases/download/launcher-v0.4.0/EDF6Launcher-0.4.0.zip)). Собирать ничего не нужно: положите exe в папку игры рядом с `EDF6.exe` и запустите. Нужен установленный EDFModLoader.

## Установка вручную

1. Установите EDFModLoader (`winmm.dll` и `EDFModLoader.dll` в папку игры).
2. Скачайте нужный мод на странице **Releases** этого репозитория.
3. Распакуйте `.dll` и `.ini` в `Mods\Plugins` в папке игры.

Плагины загружаются в алфавитном порядке; моды совместимы друг с другом.

## Сборка

Нужна Visual Studio 2019/2022 с компонентом «Разработка классических приложений на C++».
Сторонний код лежит в [deps](deps/) (MinHook, Dear ImGui, PluginAPI.h).

```bat
EDFStats\build.bat
SpectateCam\build.bat
MortarCam\build.bat
```

Готовые файлы появляются в `<мод>\out`. Если задать переменную `EDF6_DIR` (папка игры),
`EDFStats\build.bat` сам скопирует плагин в `Mods\Plugins`.
